The Problem

Two protocols.
Neither is right.

For 40 years, apps chose between TCP (reliable but slow) and UDP (fast but chaotic). Real-time pair programming needs both behaviors simultaneously.
TCP
Reliable & ordered
Every byte arrives, in order. But one lost packet blocks everything behind it (head-of-line blocking). 2-3 RTT handshake.
UDP
Fast & unreliable
Fire-and-forget packets. No encryption, no congestion control. Every real-time app reimplements reliability ad-hoc on top.
Pair programming needs reliable keyboard events AND lossy cursor updates AND prioritized media streams — on one connection.
The Foundation

QUIC changes everything.

Built on UDP. Standardized as RFC 9000. Mandatory TLS 1.3 encryption. Multiplexed streams with no head-of-line blocking. And native unreliable datagrams.

P2P Layer

iroh makes peers
find each other.

QUIC handles the protocol. But peers are behind NATs. iroh (by n0) solves discovery, hole-punching, and relay fallback — all in Rust.
Direct P2P ~90% Relay fallback ~10%

ed25519 public key = EndpointId. One per process. No accounts, no servers.

Layer Stack

Four layers.
Each solves one problem.

UDP moves raw packets. QUIC adds encryption and streams. moq-lite adds media pub/sub. hang adds codec semantics. Pairwire composes them.

Connection Setup

1 RTT to
handshake.

The entire connection — TLS negotiation, capability exchange, codec selection — completes before the first video frame ships.
Version check
Protocol versions must match exactly. No backwards compat yet.
Capability intersection
Both sides list caps. Session uses the intersection.
Codec negotiation
First mutual video + audio codec wins. H.264 + Opus today.
Display info
Host sends resolution + Retina scale. Guest knows what to expect.
Wire Protocol

Every message
on the wire.

All types live in crates/protocol/. Serialized with postcard (compact binary, no field names). Length-prefixed for framing.
postcard is NOT self-describing. Both sides must agree on exact type layout. That's why we version the protocol.
Control Stream (bidirectional, reliable)
Handshake — version, capabilities, codecs, display info
ControlHandoff — grant/revoke remote control
SetSharing — toggle screen/audio sharing
Goodbye — clean disconnect with reason
Input Stream (unidirectional, guest → host)
Key — key_code + modifiers (shift, ctrl, alt, meta)

CursorUpdate — peer_id, x, y, visible, click_animation

Adaptation

The encoder
adapts in
real-time.

A QualityMonitor polls QUIC connection stats every 1 second. When conditions change, it pushes new encoder config via a watch channel — no encoder restart.
Hysteresis: 3 consecutive "Full" samples required before upgrading. Prevents oscillation during transient congestion.

The Future

From P2P to
rooms to web.

The layered stack was designed to grow. moq-lite's pub/sub model naturally supports relay-based multi-party. hang's WebCodecs alignment enables browser viewers.
Star topology
Host = hub. Encode once, broadcast::channel to all guests. Each guest gets independent quality.
moq-relay
Host uploads once to relay. Relay fans out to N guests. Host upload = constant regardless of N.
Web viewer
WebTransport + WebCodecs = browser client. No download. Just a URL. hang frames play natively.
