The Moat

Infrastructure is the
paid-tier lock-in.

Free tier builds trust. The relay network enables features that physically can't exist P2P. That's the product moat — not price, not features, but infrastructure.
QUIC TLS 1.3 means the relay cannot read session content. It can only route, timestamp, and count. Recording and transcription are opt-in features that run at the relay — not surveillance.
Relay topology
Root (discovery only)
├── Leaf US ←→ Leaf EU
└──────────→ Leaf APAC
(NxN mesh, 2 hops max)
01
Relay as SFU
moq-relay (from moq-dev/moq) handles fan-out. Host uploads once regardless of guest count. v1 uses Cloudflare's anycast relay — zero ops. v2 operates own nodes for feature control.
02
Recording at the relay
Relay taps hang tracks → object storage. Playback via web viewer. Opt-in. Can't exist in P2P — there's no third-party to write to disk.
03
Live transcription
audio/asr simulcast track (16kHz mono Opus) forwarded to Whisper worker at relay. Captions streamed back as a hang text track. P2P can't run Whisper on behalf of both peers.
04
Protocol is the moat
moq-lite + hang is an open standard. But operating a low-latency, globally-distributed relay network on top of it takes time and capital. Cloudflare could compete — but you'll get there first among developer tools.
