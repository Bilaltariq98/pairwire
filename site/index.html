Roughly how it works

Three steps. No accounts, no calls to schedule.

  1. Host

    Open Pairwire, click Host. You get an invite link. Send it to whoever you’re pairing with — Slack, iMessage, whatever’s open.

  2. Join

    They open the link or paste it into Join. Your screen appears on their end. They can talk and draw on it. No account on either side. The link is the invite.

  3. Pair

    It’s a direct device-to-device connection over QUIC (iroh) — encrypted end-to-end. Your screen and audio are never stored on a server. NAT traversal via a relay when a direct path isn’t possible — relay sees only ciphertext.

Opening it the first time

macOS will object. Here’s how to get past it. All text below — readable by screen readers, no screenshots required.

Gatekeeper: "cannot be opened" — System Settings ▸ Open Anyway

Pairwire is not signed with an Apple Developer certificate yet. macOS Gatekeeper will block it on first launch. This takes about 30 seconds to work around.

  1. 1 Double-click pairwire-macos.dmg to mount it. Drag Pairwire to your Applications folder.
  2. 2 Double-click Pairwire in Applications. macOS shows: "Pairwire cannot be opened because Apple cannot check it for malicious software." Click Done — do not click Move to Trash.
  3. 3 Go to System Settings → Privacy & Security. Scroll to the Security section. You’ll see: "Pairwire was blocked from use because it is not from an identified developer."
  4. 4 Click Open Anyway. Enter your macOS password when prompted. Click OK.
  5. 5 Double-click Pairwire in Applications again. macOS shows a final confirmation dialog — click Open. It launches. macOS remembers your choice for this build.
After step 5, you won’t see this dialog again for this build. When a new version is downloaded, you’ll need to repeat it once.
Screen Recording + Microphone — granting permissions on first launch

macOS requires explicit permission before Pairwire can capture your screen or use the microphone. You’ll see these prompts on first launch. Grant them, then reopen the app.

  1. 1 Launch Pairwire. macOS shows: "Pairwire would like to record your screen." Click Open System Settings.
  2. 2 In System Settings → Privacy & Security → Screen Recording, find Pairwire and toggle it on.
  3. 3 Click Quit & Reopen when prompted. Pairwire restarts with screen capture enabled.
  4. 4 On first launch with audio, macOS asks for Microphone access. Click Allow. If you missed it: System Settings → Privacy & Security → Microphone → toggle Pairwire on.
Both permissions persist across relaunches — you won’t be prompted again unless you revoke them in System Settings.
